# Автономный датчик температуры, влажности и давления
Показывает данные на OLED дисплее по нажатию кнопки. 
> **Статус проекта:** законченный прототип (MVP).
### Основные функции:
* Вывод данных о температуре, влажности и давлении на OLED 0.96" дисплей
* Низкое потребление энергии в режиме ожидания
* Отображение уровня заряда
