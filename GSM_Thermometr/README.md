Термометр с GSM
Термометр должен отправлять данные в СМС, что решает проблему отсутствия интернета в отдалённых от города местах.
Проект сделан только частично. Функции, которые не были реализованы:
    1. Опрос датчика температуры
    2. Отправка данных с определённой частотой
    3. Энергосбережение
