# Термометр с GSM
Автономный термометр, который отправляет данные в СМС, что решает проблему отсутствия интернета в отдалённых от города местах.
> **Статус проекта:** Проект сделан только частично (рабочий прототип модуля связи). 

### Функции, которые не были реализованы:
* Опрос датчика температуры
* Отправка данных с определённой частотой
* Энергосбережение
